## 二、主线：三个算法只差一个 target

把三份代码摊开对比，`agent.learn()` 里真正变化的只有 `target_Q` 这一行，其余（采样、探索、学习率、更新顺序）完全一样。

| 算法 | target 怎么算 | 策略类型 | Q 的表示 | 代码位置 |
|---|---|---|---|---|
| **SARSA** | `r + γ·Q(s', a')`，`a'` 由**当前策略**采出 | on-policy | 表格 `(48,4)` | `lesson2/sarsa/agent.py:learn` |
| **Q-learning** | `r + γ·max_a Q(s', a)` | off-policy | 表格 `(48,4)` | `lesson2/q_learning/agent.py:learn` |
| **DQN** | `r + (1−done)·γ·max_a Q_target(s', a; θ⁻)` | off-policy | 神经网络 `θ` + 目标网络 `θ⁻` | `lesson3/dqn/algorithm.py:learn` |

三者的统一形式：

```
Q(s,a) ← Q(s,a) + α · [ target − Q(s,a) ]
```

**关键差别只有两处**：

1. **target 里的下一动作从哪来**。SARSA 用实际要执行的动作 `a'`（所以策略必须"老实"，探索时掉崖的后果会被如实学进去）；Q-learning 和 DQN 用 `max`（不管实际走哪条，只问"下一状态最好的选择值多少"）。
2. **Q 存在哪**。表格能存时就用表格；状态爆炸/连续时必须换成函数逼近，于是 DQN 多出目标网络和经验回放两个工程零件。

> 我的判断：课程把 SARSA 和 Q-learning 放在同一节讲是对的，但顺序容易让人误以为 Q-learning 是"更高级的 SARSA"。实际上二者是**对同一目标的两种估计视角**——SARSA 估的是"我按当前策略走下去能拿多少"，Q-learning 估的是"这个状态交换给最优玩家能拿多少"。CliffWalking 是能一眼看出这个差别的最小实验。

## 三、SARSA vs Q-learning：CliffWalking 实验

### 3.1 设置

环境 `CliffWalking-v0`：12×4 格子，起点 (3,0)，终点 (3,11)，底下 10 格是悬崖。每步 −1，掉崖 −100 并回到起点，最优路径 13 步、回报 −13。

| 组 | 目的 | 超参 | 局数 |
|---|---|---|---|
| **A 统一超参** | 公平对比 | α=0.1, γ=0.9, ε=0.1 | 500 |
| **B 课程原始** | 还原课程结论 | SARSA: α=0.1, γ=**1.0**, ε=**0.2**<br>Q-learning: α=0.1, γ=0.9, ε=0.1 | 2000 / 500 |

每个配置 5 个 seed（0–4），每 10 局做一次**贪心评估**（ε=0，3 局取均值），训练结束导出 Q 表并提取贪心路径。

⚠️ **B 组的两组超参本来就不一致**（γ 和 ε 都不同），所以 B 组只能各自看趋势，不能横向比。真正的对比在 A 组。

### 3.2 结果

| 组 · 算法 | 末 100 局训练回报 | 贪心评估回报 | 首次贪心达标 (ep) | 掉崖次数<br>/100 局 | 贪心路径步数 |
|---|---|---|---|---|---|
| A · SARSA | **−22.6** ± 2.2 | −16.5 ※ | 未达到 | **3.8** | 3 ※ / 17 / 15 / 17 / 17 |
| A · Q-learning | −44.6 ± 5.9 | **−13.0** | 190–260（中位 220） | 27.8 | **13 / 13 / 13 / 13 / 13** |
| B · SARSA | −30.4 ± 1.6 | −16.6 | 未达到 | 9.2 | 17 / 17 / 17 / 15 / 17 |
| B · Q-learning | −44.6 ± 5.9 | −13.0 | 190–260 | 27.8 | 13（同 A 组） |

※ A 组 SARSA 的贪心评估按 5 个 seed 平均是 **−53.2**，因为 seed 0 退化成了 −200，把均值拉坏；剔除该 seed 后是 −16.5。路径一栏的 `3` 也是这同一个 seed——它不是"更快"，而是撞墙自循环，实际永远到不了终点。详见 §3.3 ④。
B 组的 Q-learning 与 A 组超参完全相同，数据是同一批，不重复跑。

![训练回报与贪心评估](results/curves.png)

### 3.3 四条结论

**① Q-learning 学到的策略更优，但它"知道"不等于"做到"。**
5 个 seed 的贪心路径全部是 13 步——沿行 2（紧邻悬崖上方那一行）横穿，评估回报稳定 −13；而训练时的实际回报只有 −44.6。原因是 ε=0.1 的探索一旦发生在悬崖边上，就是 −100。**greedy 策略最优 ≠ 带探索的执行最优**，这是 off-policy 的固有代价。

**② SARSA 训练更安全，代价是策略更保守。**
掉崖 3.8 次/百局，是 Q-learning 的 1/7；贪心路径 15–17 步，走在离悬崖远一格的**行 1**，个别 seed 甚至绕到最上的行 0（seed 1 路径：`(3,0)→(2,0)→(1,0)→(0,0)→(0,1)…(0,4)→(1,4)…(1,11)→(3,11)`）。原因是 on-policy 更新把"我自己会随机乱走"这个事实算进了 Q 值——悬崖边的格子 Q 值被自身的探索惩罚压低，于是最优动作变成远离悬崖。

**③ 掉崖次数与学到的路径长度直接对得上。**
| 算法 | 掉崖/百局 | 贪心路径 | 一句话 |
|---|---|---|---|
| SARSA | 3.8 | 15–17 步（保守） | 怕死，所以绕远 |
| Q-learning | 27.8 | 13 步（最优） | 不怕死，所以贴着走 |

这不是巧合：Q-learning 的 target 用 `max`，把"下一步选最好的"当成既定事实，完全忽略自己 10% 概率会随机走。收敛出来的 Q 值在悬崖边上被高估，所以贪心路径敢贴边。

**④ seed 0 的 SARSA 学崩了——自环动作的伪不动点。**

A 组 SARSA 的 seed 0 贪心路径是 `(3,0) → (2,0) → (1,0) → (1,0) → …`，3 步就进死循环，评估回报 −200（撞满 200 步上限）。查 Q 表：

```
s=12 (1,0)  Q(上,右,下,左) = [-7.66, -7.65, -7.82, -7.65]   argmax → 左
```

"左"是墙，撞上去状态不变。**正常动作的 Q 值（−7.65）和撞墙动作的 Q 值（−7.65）已经无法区分**，任何一点更新噪声都会让 `argmax` 选到墙。一旦选中，agent 就永久卡在原地——因为 `Q(s,墙) = −1 + γ·Q(s,·)` 是一个自指的固定点，解出来 ≈ `−1/(1−γ) = −10`（γ=0.9），与真实值 −7 相差不远，所以它看起来"像个正常值"，不会自我纠正。

三个推论：

- **γ 越接近 1，自环固定点越深**（γ=0.99 时是 −100），越难逃出来。B 组用 γ=1.0 反而没出现（自环方程无解，Q 值会被持续拉低）。
- 课程的 `predict()` 用 `np.random.choice` 在并列最大值里随机选，天然能跳出；我这个实验为了可复现用确定性 `argmax`，把这个坑暴露了出来。**两个都"对"，但确定性 argmax 在自环状态上更危险。**
- 工程含义：**动作空间里存在"无效动作/原地动作"时，必须显式屏蔽**（置 −inf），不能指望 Q 值自己学会不选它。这一条直接关系到组里调度项目的动作 mask。

## 四、DQN：把 Q 表换成网络后，多出来的三个零件

### 4.1 为什么表格不够

CliffWalking 只有 48 个状态，`(48,4)` 的数组够了。但真实问题的状态是连续的（CartPole 的 4 维浮点）或组合爆炸的（调度里"已排工序集合"），表格无法枚举。**函数逼近**就是用一个参数化的 `Q(s,a;θ)` 代替查表，学习从"更新一格"变成"更新 θ"。

但直接换会同时引入三个新问题，DQN 的三个零件正是逐一对应：

| 问题 | 后果 | DQN 的解法 | 代码 |
|---|---|---|---|
| 相邻样本强相关，不满足 i.i.d. | 梯度方差大、训练震荡 | **经验回放**：`deque(maxlen=200000)` 随机采样 | `replay_memory.py` |
| target 里含待优化的 θ 本身 | "自己追自己"，目标每步漂移 | **目标网络**：`θ⁻` 每 200 步从 θ 硬同步 | `agent.py:update_target_steps=200` |
| `max` 操作把估计噪声也取上去 | Q 值系统性高估，策略被锁在高估动作上 | **本实现没处理**——要靠 Double DQN 换解耦的选动作/估值网络 | 待下周实验 |

### 4.2 损失与 target

```python
# algorithm.py —— 只保留骨架
pred_values = self.model(obs)                       # Q(s,·;θ)，形状 (B, act_dim)
action_onehot = one_hot(action, act_dim)            # a → one-hot
pred_value = (pred_values * action_onehot).sum(1)   # 取出 Q(s,a;θ)

with paddle.no_grad():                              # target 不回传梯度
    max_v = self.target_model(next_obs).max(1)      # max_a' Q(s',a';θ⁻)
    target = reward + (1 - terminal) * self.gamma * max_v

loss = mse(pred_value, target)
```

三个细节值得记：

1. **`(1 - terminal)` 和表格版 `if done: target = reward` 是同一件事**——都是"终止状态不再自举"。写成乘法是为了整批计算，不用分支。
2. **`no_grad()` 不是可选项**。漏掉它，梯度会顺着 target 回流到 θ⁻ 甚至 θ，等于把"目标"也当成待优化的变量，训练会直接崩。
3. **target 网络是硬同步（每 200 步 copy 权重），不是软更新**。课程这套实现没有 Polyak 平均，所以同步瞬间会有一次 loss 跳变。

### 4.3 训练循环的四个超参

| 参数 | 值 | 作用 |
|---|---|---|
| `MEMORY_WARMUP_SIZE` | 200 | 先攒够经验再开始学，避免早期样本全是随机动作 |
| `LEARN_FREQ` | 5 | 每 5 个环境步学一次（环境采样比反向传播便宜） |
| `BATCH_SIZE` | 64 | 每次从回放池随机抽 64 条 |
| `e_greed` | 0.1 → 0.01，衰减 1e-6/step | 随训练逐步降低探索 |

### 4.4 冒烟验证

```
[ OK ] lesson3 dqn   DQN sample=1  learn_loss=1.3201
```

构造、采样、前向、单步反传都通过，`loss` 是随机初始化网络在随机 batch 上的首个 MSE，符合预期量级。**训练收敛性未验证，下周补。**
