## S8 ⬜ 合法性检查器 ★★（4–6 小时）

**先写 `validator.py`，再写 `assembly_env.py`。** 顺序反了会写成一团。

`envs/validator.py`：

```python
def check_action(inst, done_set, action, station_free_at, now):
    """返回 (ok, reason)。任何一步非法都必须被抓住。"""
    op = inst.ops[action]
    if action in done_set:
        return False, "already_scheduled"
    if not all(p in done_set for p in op.predecessors):
        return False, "predecessor_not_done"
    if station_free_at[op.station] > now:
        return False, "station_busy"
    for skill, lvl in op.skill_req.items():
        if not any(w["skills"].get(skill, 0) >= lvl for w in inst.workers.values()):
            return False, f"skill_unavailable:{skill}"
    return True, "ok"


def feasible_mask(inst, done_set, station_free_at, now):
    """给策略网络用的布尔 mask，必须和 check_action 逐位一致。"""
    return [check_action(inst, done_set, i, station_free_at, now)[0]
            for i in range(len(inst.ops))]
```

## S12 ⬜ GIN 编码器 + 打分头（3 小时）

`models/gin.py`：

```python
class GINLayer(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.eps = nn.Parameter(torch.zeros(1))
        self.mlp = nn.Sequential(nn.Linear(dim, dim), nn.ReLU(), nn.Linear(dim, dim))

    def forward(self, h, edge_index):
        src, dst = edge_index[1], edge_index[0]     # 消息 src -> dst
        agg = torch.zeros_like(h).index_add_(0, dst, h[src])
        return self.mlp((1 + self.eps) * h + agg)


class GINEncoder(nn.Module):
    def __init__(self, in_dim, dim, n_layers=3):
        super().__init__()
        self.inp = nn.Linear(in_dim, dim)
        self.layers = nn.ModuleList([GINLayer(dim) for _ in range(n_layers)])
        self.norm = nn.LayerNorm(dim)

    def forward(self, x, edge_index):
        h = self.inp(x)
        for layer in self.layers:
            h = h + layer(h, edge_index)            # 残差
        return self.norm(h)
```

打分头 + mask：

```python
logits = self.score(h).squeeze(-1)
logits = logits.masked_fill(~feasible_mask, -1e9)   # 用 -1e9，不用 -inf
dist = torch.distributions.Categorical(logits=logits)
```

⚠️ **边必须单向**：`predecessor → successor`。双向会让后继信息混进聚合。
⚠️ **必须加 LayerNorm**：GIN 的 sum 聚合数值随节点数线性放大。

## 卡壳决策树

训练不收敛时**按顺序排查，不要跳步**：

```
reward 完全不涨
├─ loss 也不动 → mask 把动作全屏蔽了
│                → 打印 mask.sum(-1)，应该落在 1~N
├─ loss 在动但 reward 不动
│  ├─ 奖励尺度不对 → makespan 几百，奖励是不是也几百？先 /100
│  └─ 环境退化 → 无论怎么选结果都一样，说明没有区分度
└─ 仍无解 → 换成随机合法策略跑，看 makespan 分布是否合理

reward 涨到一半崩
├─ lr 太大 → 降到 1e-4
├─ 没梯度裁剪 → clip_grad_norm_(params, 0.5)
└─ GIN 数值爆了 → 确认 LayerNorm 存在

小规模能训，大规模崩
├─ GIN sum 聚合随节点数放大 → 加 LayerNorm + 降 lr
└─ 采样量不够 → num_steps 提到 4096
```

**问题分布经验值**：mask 逻辑 50%、奖励尺度 30%、超参 15%、网络结构 5%。
→ **别一上来怀疑 GIN。**
